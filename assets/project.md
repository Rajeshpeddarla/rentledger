## 4. Detailed Feature Workflows & Math Rules

### 4.1 Add Inventory Item & Smart Rate Auto-Calculator
* **Inputs:**
    * `Item Photo` (1 image -> compressed to WebP -> uploaded to Cloudflare R2).
    * `Item Name` & `Description`.
    * `Total Stock Quantity` (Default `1`, allows multi-unit items like 10 drills or 50 chairs).
    * `Security Deposit Amount` (Default expected deposit when renting this item).
    * **Rate Fields:** `Hourly Rate`, `Daily Rate`, `Weekly Rate`, `Monthly Rate`.
* **Smart Auto-Calculation Logic:**
    * To prevent unrealistic 24x multiplication traps, when the owner enters either **Hourly Rate** or **Daily Rate**, the Cubit automatically suggests editable industry-standard multipliers in the untouched fields:
        * $\text{Daily Rate} = \text{Hourly Rate} \times 8$
        * $\text{Weekly Rate} = \text{Daily Rate} \times 6$
        * $\text{Monthly Rate} = \text{Daily Rate} \times 22$
    * **Manual Override Rule:** Each rate field tracks an `isManuallyEdited` flag in the form state. If the shop owner manually edits the Weekly or Monthly field, typing in Hourly/Daily will not overwrite their custom value.

### 4.2 "Lend / Rent Out Item" Workflow
1. **Select Item:** Choose from available inventory (or pre-selected if launched from Inventory tab).
2. **Select Rental Dates & Conflict Check:**
    * Pick `Start Date & Time` and `Expected End Date & Time`.
    * **Database Conflict Check:** Queries Supabase to ensure the number of overlapping `active` or `upcoming` leases for that `item_id` does not exceed `total_quantity`:
      $$\text{Overlap Condition: } (\text{NewStart} < \text{ExistingExpectedEnd}) \land (\text{NewEnd} > \text{ExistingStart}) \land (\text{Status} \in [\text{'active'}, \text{'upcoming'}])$$
    * If all units are booked for those dates, blocks creation and displays the conflicting lease details.
3. **Customer Details (Repeat Customer Auto-Fill):**
    * Search bar at top: `"Select Repeat Customer"` (searches by Name or Phone). Selecting a saved customer auto-fills `Name`, `Phone`, `Email`, and their saved `ID Proof Image`.
    * For new customers: Enter `Name` (Req), `Phone` (Req), `Email` (Optional), `ID Proof Image` (Optional — 1 photo uploaded to R2).
4. **Condition Proof ("Before" Photos):**
    * Owner snaps **2 to 3 photos** of the item before handing it over -> compressed to WebP -> uploaded to Cloudflare R2.
5. **Upfront Deposit & Payment Collection:**
    * Displays item's `Expected Security Deposit` (e.g., `₹2,000`).
    * Toggle: `Full Deposit Paid` | `Partial Deposit Paid` | `Zero Deposit`.
    * Input: `Deposit Amount Paid Now` (e.g., `₹1,000`) and optional `Advance Rent Paid Now` (e.g., `₹0`).
6. **Confirm Lend & Share Receipt:**
    * Clicking **Lend Item** saves the lease in Supabase (`status = 'active'` if start time is today/now, or `'upcoming'` if future).
    * Generates a **Handover & Deposit Receipt PDF** containing store details, item details, start/end timestamps, deposit paid, and "Before" photos (Pro).
    * Opens 1-tap share sheet to send directly to the customer's **WhatsApp** (`https://wa.me/{phone}`) or **Email**.

### 4.3 "Take Back Item" (Early / On-Time / Late Return & Settlement)
When the customer returns the item (early, on time, or late), the owner opens the active lease and taps **Take Back Item**:

1. **Condition Verification:**
    * Displays the **2–3 "Before" photos** taken at handover so the owner can inspect the item for damages before settling.
2. **Automated Duration & Rent Calculation:**
    * Compares `actual_return_time` (current server timestamp, editable by owner if needed) against `start_time`:
      $$\Delta t = \text{ActualReturnTime} - \text{StartTime}$$
    * **Tiered Rate Selection:**
        * If $\Delta t < 24\text{ hours}$ (and `rate_hourly > 0`): $\text{CalculatedRent} = \lceil \text{Hours} \rceil \times \text{rate\_hourly}$ (capped at `rate_daily` if $\text{Hours} \times \text{rate\_hourly} > \text{rate\_daily}$ for single-day returns, with a 1-tap toggle to switch between Hourly vs. Daily billing).
        * If $\Delta t \ge 24\text{ hours}$: Calculates total days/weeks/months + remaining hours based on the item's configured rates.
    * Displays a badge: `Returned Early (Calculatd by actual hours used)`, `On Time`, or `Late Return (+X hours overdue)`.
3. **Adjustments (Discounts & Damage/Late Fees):**
    * Input: `Discount Amount` (Optional, `- ₹`)
    * Input: `Damage / Late Fee` (Optional, `+ ₹`)
4. **Final Settlement Formula:**
   $$\text{Net Rent Due} = \text{CalculatedRent} - \text{Discount} + \text{DamageOrLateFee}$$
   $$\text{Upfront Credits} = \text{DepositPaid} + \text{AdvanceRentPaid}$$
   $$\text{Final Balance} = \text{Net Rent Due} - \text{Upfront Credits}$$
    * **Scenario A ($\text{Final Balance} > 0$ — Customer Owes Money):**
        * UI Banner: **`Collect from Customer: ₹{Final Balance}`**
        * Button: **`Show Payment QR`** $\rightarrow$ Opens modal showing the owner's uploaded Payment QR image (and for Pro users with a UPI ID, renders a dynamic UPI QR code `upi://pay?pa={upi_id}&pn={store_name}&am={FinalBalance}&cu=INR`).
    * **Scenario B ($\text{Final Balance} < 0$ — Refund Deposit to Customer):**
        * UI Banner: **`Refund to Customer: ₹{abs(Final Balance)}`** (Rent automatically deducted from deposit held).
    * **Scenario C ($\text{Final Balance} == 0$):**
        * UI Banner: **`Fully Settled (₹0 Balance)`**
5. **Release Item & Send Settlement Receipt:**
    * Tapping **Confirm Payment & Release Item** updates `status = 'returned'` and `actual_return_time = now()` in Supabase.
    * The item is immediately released back into available inventory for new leases.
    * Generates a **Final Return & Settlement PDF Receipt** and shares via WhatsApp or Email.

## 5. Account Security, Subscriptions & Monetization Flow

### 5.1 Free vs. Pro Tier Matrix

| Feature | Free Tier (AdMob Supported) | Pro Monthly (`₹249/mo` / `$6.99/mo`) & Pro Annual (`₹1,999/yr` / `$49.99/yr`) |
| :--- | :--- | :--- |
| **Inventory Items Limit** | Max **10 active items** | **Unlimited** items |
| **Monthly Leases Limit** | Max **15 leases / month** | **Unlimited** leases |
| **PDF Receipts** | Standard receipt with `"Managed with RentLedger"` watermark | **Custom Store Logo**, zero watermark, embedded **Before condition photos** |
| **Payment QR at Checkout** | Static uploaded QR image | **Dynamic Auto-Amount UPI QR Code** + Static QR |
| **Weekly & Monthly Reports** | View summary metrics on screen | **Download PDF & Excel (CSV)** item-wise & customer-wise reports |
| **Advertisements** | Frequency-capped Banner & Post-Action Interstitial Ads | **100% Ad-Free** |

### 5.2 "Secure Account FIRST, Then Upgrade" Flow
To guarantee no Pro subscriber ever loses their cloud data if they lose or reset their phone, **account linking is enforced right before launching Google Play Billing**:

1. User taps **"Upgrade to Pro"** (from Profile or when hitting the 10-item / 15-lease free limit).
2. `SubscriptionCubit` checks `supabase.auth.currentUser?.isAnonymous`.
3. **If `isAnonymous == true`:**
    * Opens the **Secure Your Store Account** bottom sheet first:
        * Inputs: `Email Address` and `Password` (min 6 chars).
        * Action calls:
          ```dart
          await supabase.auth.updateUser(
            UserAttributes(email: email, password: password),
          );
          ```
    * **Critical Advantage:** `updateUser` converts the anonymous user into a permanent email/password user **while keeping the exact same `auth.uid()`**. Zero database rows or R2 files need migration.
4. **If `isAnonymous == false` (or immediately after step 3 succeeds):**
    * Launches the Google Play Billing purchase flow (`InAppPurchase.instance.buyNonConsumable`).
    * On `PurchaseStatus.purchased`, calls the Supabase Edge Function `verify-purchase` to validate the token and set `plan_tier = 'pro_monthly'` or `'pro_annual'`.

```sql
-- 7A. Enforce Free Tier Inventory Limit (Max 10 Items)
CREATE OR REPLACE FUNCTION public.enforce_inventory_limit()
RETURNS TRIGGER AS $$
DECLARE
  v_plan TEXT;
  v_count INT;
BEGIN
  SELECT plan_tier INTO v_plan FROM public.stores WHERE id = NEW.store_id;
  IF v_plan = 'free' THEN
    SELECT COUNT(*) INTO v_count FROM public.inventory_items
    WHERE store_id = NEW.store_id AND is_archived = false;
    IF v_count >= 10 THEN
      RAISE EXCEPTION 'FREE_ITEM_LIMIT_REACHED: Upgrade to Pro to add more than 10 inventory items.';
    END IF;
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER trg_enforce_inventory_limit
BEFORE INSERT ON public.inventory_items
FOR EACH ROW EXECUTE FUNCTION public.enforce_inventory_limit();

-- 7B. Enforce Free Tier Monthly Lease Limit (Max 15 Leases/Month) & Date Conflict Check
CREATE OR REPLACE FUNCTION public.validate_lease_before_insert()
RETURNS TRIGGER AS $$
DECLARE
  v_plan TEXT;
  v_monthly_leases INT;
  v_item_qty INT;
  v_overlapping_leases INT;
BEGIN
  -- 1. Check Free Tier Monthly Quota
  SELECT plan_tier INTO v_plan FROM public.stores WHERE id = NEW.store_id;
  IF v_plan = 'free' THEN
    SELECT COUNT(*) INTO v_monthly_leases FROM public.leases
    WHERE store_id = NEW.store_id
      AND date_trunc('month', created_at) = date_trunc('month', now());
    IF v_monthly_leases >= 15 THEN
      RAISE EXCEPTION 'FREE_LEASE_LIMIT_REACHED: Upgrade to Pro for unlimited monthly leases.';
    END IF;
  END IF;

  -- 2. Check Stock Availability for Overlapping Dates
  SELECT total_quantity INTO v_item_qty FROM public.inventory_items WHERE id = NEW.item_id;
  SELECT COUNT(*) INTO v_overlapping_leases FROM public.leases
  WHERE item_id = NEW.item_id
    AND status IN ('active', 'upcoming')
    AND (NEW.start_time < expected_end_time AND NEW.expected_end_time > start_time);

  IF v_overlapping_leases >= v_item_qty THEN
    RAISE EXCEPTION 'ITEM_ALREADY_LEASED: All units of this item are already booked for the selected dates.';
  END IF;

  -- 3. Increment Customer Lease Counter
  UPDATE public.customers SET total_leases_count = total_leases_count + 1 WHERE id = NEW.customer_id;

  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER trg_validate_lease_insert
BEFORE INSERT ON public.leases
FOR EACH ROW EXECUTE FUNCTION public.validate_lease_before_insert();
```

```typescript
  const authHeader = req.headers.get("Authorization")!;
  const supabase = createClient(
    Deno.env.get("SUPABASE_URL")!,
    Deno.env.get("SUPABASE_ANON_KEY")!,
    { global: { headers: { Authorization: authHeader } } }
  );

  const { data: { user }, error } = await supabase.auth.getUser();
  if (error || !user) return new Response("Unauthorized", { status: 401 });

  const { folder, filename } = await req.json();
  // Enforce tenant isolation inside bucket path
  const objectKey = `stores/${user.id}/${folder}/${filename}`;

  const command = new PutObjectCommand({
    Bucket: Deno.env.get("R2_BUCKET_NAME")!,
    Key: objectKey,
    ContentType: "image/webp",
  });

  const uploadUrl = await getSignedUrl(s3, command, { expiresIn: 60 });
  const publicUrl = `${Deno.env.get("R2_PUBLIC_DOMAIN")}/${objectKey}`;

  return new Response(JSON.stringify({ uploadUrl, publicUrl }), {
    headers: { "Content-Type": "application/json" },
  });
});
```

### 8.2 Core Utility Logic: Smart Rate Auto-Calculation & Return Settlement (`rate_calculator.dart`)

```dart
class RateCalculator {
  /// Auto-calculates suggested rates when Hourly or Daily rate is entered
  static Map<String, double> suggestRates({
    double? hourly,
    double? daily,
  }) {
    if (hourly != null && hourly > 0) {
      final calcDaily = hourly * 8; // Standard 8-hour rental day
      return {
        'hourly': hourly,
        'daily': calcDaily,
        'weekly': calcDaily * 6,   // 6 days price for 7-day week
        'monthly': calcDaily * 22, // 22 days price for 30-day month
      };
    } else if (daily != null && daily > 0) {
      return {
        'hourly': double.parse((daily / 8).toStringAsFixed(2)),
        'daily': daily,
        'weekly': daily * 6,
        'monthly': daily * 22,
      };
    }
    return {'hourly': 0, 'daily': 0, 'weekly': 0, 'monthly': 0};
  }

  /// Calculates actual rent based on duration between startTime and actualReturnTime
  static double calculateReturnRent({
    required DateTime startTime,
    required DateTime actualReturnTime,
    required double rateHourly,
    required double rateDaily,
    required double rateWeekly,
    required double rateMonthly,
    String billingMode = 'auto', // 'auto', 'hourly', 'daily'
  }) {
    final duration = actualReturnTime.difference(startTime);
    final totalMinutes = duration.inMinutes < 1 ? 1 : duration.inMinutes;
    final totalHours = (totalMinutes / 60).ceil();

    if (billingMode == 'hourly' && rateHourly > 0) {
      return totalHours * rateHourly;
    }

    if (billingMode == 'daily' && rateDaily > 0) {
      final days = (totalHours / 24).ceil();
      return (days < 1 ? 1 : days) * rateDaily;
    }

    // Auto Mode: Smart optimal calculation for early/late returns
    if (totalHours < 24 && rateHourly > 0) {
      final hourlyCost = totalHours * rateHourly;
      // Cap single-day hourly cost at daily rate if daily rate is configured
      if (rateDaily > 0 && hourlyCost > rateDaily) {
        return rateDaily;
      }
      return hourlyCost;
    }

    final totalDays = (totalHours / 24).floor();
    final remainingHours = totalHours % 24;

    double totalRent = 0;
    int daysLeft = totalDays;

    if (rateMonthly > 0 && daysLeft >= 30) {
      final months = daysLeft ~/ 30;
      totalRent += months * rateMonthly;
      daysLeft = daysLeft % 30;
    }

    if (rateWeekly > 0 && daysLeft >= 7) {
      final weeks = daysLeft ~/ 7;
      totalRent += weeks * rateWeekly;
      daysLeft = daysLeft % 7;
    }

    if (rateDaily > 0 && daysLeft > 0) {
      totalRent += daysLeft * rateDaily;
    } else if (rateDaily == 0 && rateHourly > 0 && daysLeft > 0) {
      totalRent += (daysLeft * 24) * rateHourly;
    }

    if (remainingHours > 0) {
      if (rateHourly > 0) {
        final extraHourly = remainingHours * rateHourly;
        totalRent += (rateDaily > 0 && extraHourly > rateDaily) ? rateDaily : extraHourly;
      } else if (rateDaily > 0) {
        totalRent += rateDaily;
      }
    }

    return totalRent;
  }
}
```
